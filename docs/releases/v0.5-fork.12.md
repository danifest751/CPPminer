# CPPminer v0.5-fork.12 — TNet on AMD and Intel

A release for **TNet** (Requant test network): it now mines on AMD and Intel GPUs too, not only NVIDIA. Pearl and
Quantus are unchanged. **TNet has no miner fee**; **Quantus is still mined without a developer fee**; the Pearl fee
is unchanged (1%).

CPPminer is based on [1640675651/CPPminer](https://github.com/1640675651/CPPminer),
the Pearl/Quantus miner by @foolzhz. Development and release builds are maintained
in this fork; upstream submissions are made only when the fork owner chooses them.

## TNet on OpenCL

```sh
cppminer --backend opencl --list-devices                       # the device's index
cppminer --algo tnet --backend opencl --device 0 --rpc 193.187.93.29:19340 --payee <64-hex key hash> --worker rig1
cppminer --algo tnet --backend opencl --selftest
cppminer --algo tnet --backend opencl --bench                  # offline ns per ticket
```

- `--backend opencl` is the default only in a build without CUDA; on an NVIDIA machine pass it to use OpenCL.
- **Intel Arc (XMX).** The GEMM runs on the matrix engines through the bundled ESIMD library
  (`kernels/libcp_esimd.so`, `kernels/cp_esimd.dll`; it gained `cp_esimd_tnet_gemm`), with `dpasw` and the operands
  packed in DPAS blocks. Without the library it uses OpenCL DPAS (about 1.7 TMAC/s on an A380). The ESIMD GEMM takes
  the batch in whole 512-row tiles: keep the default `--batch 8192` or any multiple of 512.
- **AMD.** RDNA3/4 use `v_dot4_i32_iu8`, GCN5/RDNA2 `v_dot4_i32_i8`; other GPUs the KHR integer dot product or plain
  multiply-adds. Integrated GPUs share memory: `--batch 1024` keeps it small.
- At start-up the miner builds the kernels and keeps the first that agrees with the CPU (`CP_TNET_NOESIMD=1`,
  `CP_TNET_OCL_NODPAS=1` and `CP_TNET_OCL_DOT=0..3` choose by hand).
- The network, the long poll and the mining loop are the ones CUDA uses: TNet's code is now split into a shared
  part and the two backends.

| GPU | GEMM | ns per ticket | M tickets/s |
|---|---|---:|---:|
| CMP 50HX (CUDA, unchanged) | CUTLASS tensor cores | 239 | 4.18 |
| Arc A380 | ESIMD `dpasw` | 1131 | 0.88 |
| Radeon 780M (integrated) | OpenCL `sudot4` | 7000 | 0.14 |

## Checked before release

- CMP 50HX (Linux, CUDA 12.9): `--selftest`; `--bench` 238.7 ns/ticket; 180 s in the Requant pool after the split:
  53 shares and a block, none rejected.
- Arc A380 (Linux, Intel OpenCL): `--selftest` (expansion, tickets, the requantizing GEMM in two layers against the
  CPU); 300 s in the pool with ESIMD: 18 shares, none rejected; earlier OpenCL builds 2 shares and a block.
- Radeon 780M (Windows, MinGW build): `--selftest`; 600 s in the pool: 8 shares, none rejected.
- Pearl and Quantus code is the same as in v0.5-fork.11.
