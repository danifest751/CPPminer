# CPPminer v0.5-fork.11 — faster TNet

A release for **TNet** (Requant test network): 16% more tickets per second on Turing and more on Ampere,
with the same results bit for bit. Pearl and Quantus are unchanged. **TNet has no miner fee**; **Quantus
is still mined without a developer fee**; the Pearl fee is unchanged (1%).

CPPminer is based on [1640675651/CPPminer](https://github.com/1640675651/CPPminer),
the Pearl/Quantus miner by @foolzhz. Development and release builds are maintained
in this fork; upstream submissions are made only when the fork owner chooses them.

## TNet

```sh
cppminer --algo tnet --rpc 193.187.93.29:19340 --payee <64-hex key hash> --worker rig1
cppminer --algo tnet --bench          # offline: ns per ticket and the time of each phase
```

- **Requantization in the GEMM epilogue.** Each layer's `clamp((y M + 2^23) >> 24, -128, 127)` runs as the
  CUTLASS epilogue, so the int32 product is never written to memory. At start-up the miner checks it
  against the CPU with two multipliers (both clamps); if it disagrees it requantizes in a separate pass,
  as before. `CP_TNET_FUSED=0` forces the separate pass. A batch of rows needs 2 instead of 6 bytes per
  element.
- **SHA-256 kernels.** The compression is unrolled, the expansion writes 16-byte vectors, and the ticket
  hash takes its fixed last block precomputed: expansion 2.71 -> 0.46 ms and ticket hashing 1.36 ->
  0.37 ms per 8192-row batch on a CMP 50HX.
- **Tiles.** 256 x 128 blocks on Turing and Ampere, chosen by measurement (`docs/tnet.md`).
- The self-test also checks the ticket hash against a known answer and the requantizing GEMM.

| GPU | v0.5-fork.10 | v0.5-fork.11 |
|---|---:|---:|
| CMP 50HX (Turing) | 277 ns/ticket, 3.61 M/s | 239 ns/ticket, 4.18 M/s |
| RTX 3090 (Ampere), clock locked at 1110 MHz | 208 ns/ticket | 193 ns/ticket |
| RTX 3090, stock clocks, in the pool | | 189 ns/ticket, 5.28 M/s (150 while cool) |

## Checked before release

- CMP 50HX (Linux, CUDA 12.9): `--selftest` with the new checks; `--bench` for every tile; 240 s in the
  Requant pool: 52 shares and 4 blocks, none rejected, 239 ns/ticket.
- RTX 3090 (Linux, CUDA 12.8, sm80 kernel): `--selftest`; `--bench` for twelve tiles with the clock locked;
  180 s in the Requant pool: 56 shares and 4 blocks, none rejected.
- Pearl and Quantus code is the same as in v0.5-fork.10.
