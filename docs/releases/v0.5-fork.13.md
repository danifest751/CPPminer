# CPPminer v0.5-fork.13 — TNet on phones

A release for **TNet** (Requant test network): it now mines on Android phones, from one file with no libraries beside
it. Pearl and Quantus are unchanged. **TNet has no miner fee**; **Quantus is still mined without a developer fee**; the
Pearl fee is unchanged (1%).

CPPminer is based on [1640675651/CPPminer](https://github.com/1640675651/CPPminer),
the Pearl/Quantus miner by @foolzhz. Development and release builds are maintained
in this fork; upstream submissions are made only when the fork owner chooses them.

## Downloads

| `cppminer-linux-x64-cuda.tar.gz` | Linux x64 (Ubuntu 24.04+ / glibc 2.39): same backends |

## TNet on a phone

```sh
tar xzf cppminer-android-arm64.tar.gz && cd cppminer-android-arm64
./cppminer --algo tnet --selftest
./cppminer --algo tnet --bench --seconds 20
./cppminer --algo tnet --rpc pool.requant.network:19340 --payee <64-hex key hash> --worker phone
```

So far it has only been run from `adb shell`, which needs USB debugging but no root. It takes about 700 MiB of memory.

| Phone | Backend | us per ticket | Tickets/s |
|---|---|---:|---:|
| POCO F7 Ultra (Snapdragon 8 Elite), battery at 36 C | cpu, I8MM | 16.6 | 60 200 |
| POCO F7 Ultra, half an hour in the pool, median (17-29) | cpu, I8MM | 22 | 45 000 |
| POCO F7 Ultra | opencl, Adreno 830, dot product | 302 | 3 300 |
| POCO X3 Pro (Snapdragon 860), cool | cpu, DotProd | 78 | 12 800 |
| POCO X3 Pro, after minutes of mining | cpu, DotProd | 120-145 | 7 000-8 300 |
| POCO X3 Pro | opencl, Adreno 640 | 972 | 1 030 |

- **CPU kernels.** I8MM (`smmla`) where the CPU has it, else DotProd (`sdot`), chosen at start-up. On every AArch64 CPU
  requantization uses `sqrdmulh`. Other CPUs run a plain C++ kernel, which is right but too slow to mine with on x86.
- **The phone's GPU** is not the default, as the CPU was 7 to 18 times faster on both phones, and it needs a build that
  links the vendor's OpenCL ([docs](https://github.com/danifest751/CPPminer/blob/release/fork/docs/tnet.md#a-phones-gpu)). On Adreno and Mali the miner uses `rq_gemm_direct` and passes of about 40 ms, as a pass
  of several seconds froze a phone until it rebooted.
- **Cores.** The miner runs at low priority and asks for all the cores before each pass, as Android switches them off
  and on and a thread's affinity stays narrowed to those that were on.

Before you leave one mining:

- **Heat.** At 45 C at the battery the miner pauses until it is down to 42 C (`CP_TNET_MAX_TEMP`, 0 turns it off). Where
  Android hides that temperature the check does nothing. Thermal services cut the clocks well before that, so the rate
  follows the temperature: the 8 Elite ran at 1.6-2.7 GHz of its 3.53 and 4.32.
- **Charge.** The miner does not watch it. On a computer's USB port the F7 Ultra lost 13% to 36% an hour, and a phone
  that runs out simply stops, so use a real charger.
- **A VPN on the phone** carries the miner's traffic too. On the F7 Ultra one stopped passing traffic to the pool, and the
  miner sat on `getwork failed` until the VPN was turned off; it then carried on by itself.

## Also in this release

- An opt-in control API for TNet on CUDA, a loopback listener that pauses and resumes mining for a device's owner, and
  device telemetry for TNet in the stats API ([docs/api.md](https://github.com/danifest751/CPPminer/blob/release/fork/docs/api.md)). Without its flags, mining is unchanged.
- Pool agent `cppminer/0.5-fork.13`.

## Checked before release

- POCO F7 Ultra, from `adb shell`: `--selftest` (I8MM, DotProd and the plain kernel against the references); Requant's
  vectors, small and at the real parameters; half an hour in the pool: 6 shares, none rejected. Later 11 shares in all,
  none rejected.
- POCO X3 Pro, from `adb shell`, before the I8MM commit: the same self-test and vectors on DotProd; pool mining with
  the pause at 45 C and the resume: block 11820 of the test network, none rejected.
- CMP 50HX (Linux, this package): `--selftest`; `--bench` 230.6 ns/ticket; 180 s in the pool: 33 shares and 4 blocks,
  none rejected. OpenCL on the same card: `--selftest`.
- Pearl and Quantus code is the same as in v0.5-fork.12.

## Not checked

- Termux: `docs/termux_note.md` describes it, but this package has only run from `adb shell`.
- Other phones. No Cortex-A510 and no Mali GPU was tried, and the requantization on DotProd has run the self-test only on
  the F7 Ultra, not on a phone without I8MM.
- Mining from a phone unplugged with its screen off: it may sleep, and the miner then waits.
- AMD and Intel GPUs on this build: their code did not change, but they were not run.
