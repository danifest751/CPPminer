# CPPminer v0.5-fork.8 — HiveOS, Docker, stats API; faster AMD

This release adds a **HiveOS custom-miner package**, **Docker images** for NVIDIA, AMD and Intel,
and a **stats API**. It also makes Pearl and Quantus faster on AMD RDNA4 and Quantus faster on
every GPU. **Quantus is still mined without a developer fee**; the Pearl fee is unchanged (1%).

CPPminer is based on [1640675651/CPPminer](https://github.com/1640675651/CPPminer),
the Pearl/Quantus miner by @foolzhz. Development and release builds are maintained
in this fork; upstream submissions are made only when the fork owner chooses them.

## HiveOS

Flight sheet with **Miner: Custom**, then **Setup Miner Config**:

| Field | Value |
|---|---|
| Installation URL | `https://github.com/danifest751/CPPminer/releases/download/v0.5-fork.8/cppminer-0.5_fork.8.tar.gz` |
| Hash algorithm | `pearl` or `quantus` |
| Wallet and worker template | `%WAL%.%WORKER_NAME%` |
| Pool URL | `stratum+tcp://prl-ru.kryptex.network:7048` (Pearl) or `stratum+tcp://qtc-ru.kryptex.network:7049` (Quantus) |
| Pass | `x` |
| Extra config arguments | optional cppminer options, e.g. `--backend opencl` |

The package finds the GPUs (nvidia-smi for NVIDIA, the OpenCL device list for AMD) and starts
one miner per GPU, each restarted if it exits. Hashrate, accepted/rejected shares, temperatures
and fans show per GPU in the dashboard. The binary is built on Ubuntu 20.04, so it runs on HiveOS
images based on Ubuntu 20.04 and newer. More: `README-hiveos.md` in the package.

## Docker

```sh
# NVIDIA (needs the NVIDIA Container Toolkit)
docker run -d --name cppminer --restart unless-stopped --gpus all -p 4068:4068 \
  -e WALLET=YOUR_KRYPTEX_ACCOUNT_OR_PRL_ADDRESS -e ALGO=pearl ghcr.io/danifest751/cppminer:nvidia

# AMD (ROCm 7.2 OpenCL in the image)
docker run -d --name cppminer --restart unless-stopped --device /dev/kfd --device /dev/dri \
  -p 4068:4068 -e WALLET=... -e ALGO=quantus ghcr.io/danifest751/cppminer:amd

# Intel Arc
docker run -d --name cppminer --restart unless-stopped --device /dev/dri -p 4068:4068 \
  -e WALLET=... -e ALGO=pearl ghcr.io/danifest751/cppminer:intel
```

Variables: `WALLET` (required), `ALGO` (`pearl` / `quantus`), `POOL` (default Kryptex RU),
`WORKER`, `PASS`, `BACKEND`, `DEVICES`, `EXTRA_ARGS`, `API_PORT`. Cppminer options can also be
passed as the container command. More: `packaging/docker/README.md`.

## Stats API

`--api-port N` serves, on `127.0.0.1:N` (`--api-bind 0.0.0.0` for all interfaces):

- `/summary`: version, algorithm, backend, pool state, uptime, hashrate over 10 s / 60 s / 15 min,
  every device with its name and PCI address, accepted and rejected shares (dev-fee sessions are
  not counted);
- `/hiveos`: the same in the form HiveOS expects.

Hashrate is in H/s; for Pearl one hash is one int8 multiply-accumulate, so TH/s equals the TMAC/s
in the log. Details: `docs/api.md`.

## What changed

### Pearl, OpenCL

- The keyed BLAKE3 matrix hash works on 32-bit words with unrolled rounds: 25× faster (R9700 per
  nonce prep 61 → 12 ms).
- The job's zero-B seed is hashed on the GPU instead of the CPU (0.78 s → milliseconds per job),
  checked against the CPU path with `CP_OCL_ZERO_B_CHECK=1`.
- New 256-wide fused A prepack: noise rows computed once, staged in padded local memory,
  coalesced stores (prep 12 → 7 ms on the R9700). It fits the 32 KB of local memory the AMD
  Windows driver allows; if a driver refuses it, the miner falls back to the previous kernel.
  `CP_OCL_PREP_CHECK=1` compares the two byte for byte.
- RDNA4: the milestone reduce-scatter works on half waves (lanes 0–15 own the top tiles,
  16–31 the bottom): +4–6%. A 64×32 WMMA wave tile is available as `CP_OCL_WMMA_WAVE_N=32`.

### Quantus

- OpenCL on RDNA4: the 128 → 64-bit reduction is written in gfx12 inline assembly around one
  multiply-add with its own carry out (a field multiply takes ~26 instead of ~33 cycles), two
  nonces per work-item and 64-bit linear layers. R9700 162 → 211 MH/s.
- OpenCL, all GPUs: the lazy row sum rides in the 32×32+64 multiply chain, and the rare carry
  fold after a lazy sum is skipped (a few hashes per million come out wrong; every candidate is
  re-hashed on the CPU before it is sent).
- CUDA: the same rare carry fold is skipped: CMP 50HX 285.5 → 300.5 MH/s.

### Packaging

- `packaging/hiveos`, `packaging/docker`, `packaging/common/cppminer-multi.sh` (one process per
  GPU with its own API port, restart on exit).
- `scripts/rental-amd`: setup for rented AMD servers, including ROCm OpenCL from the
  distribution on Ubuntu 25.04+.
- Pool agent `cppminer/0.5-fork.8`.
